# v1.0.0-rc.4.1 final release gate

The source reports `v1.0.0-rc.4.1`. Merging this candidate does not tag or
publish a release and does not update the Homebrew tap.

Before creating the annotated tag:

1. CI must pass on the merged `main` commit.
2. The qualification commands in
   [`v1.0.0-rc.4.1-qualification.md`](v1.0.0-rc.4.1-qualification.md) must
   pass from that exact commit.
3. `promptgrinder --version` must report `v1.0.0-rc.4.1`.
4. The source-only release and Homebrew-update workflows must validate without
   publishing or writing to the tap.
5. A maintainer must explicitly authorize the annotated
   `v1.0.0-rc.4.1` tag and its push.
