# PromptGrinder v1.0.0-rc.1 release notes — draft

Status: not released. Do not publish these notes until
`docs/release/final-gate.md` records `GO` for the exact tagged artifacts.

PromptGrinder v1.0.0-rc.1 is a local macOS command-line application that executes
Markdown work orders through the Codex CLI, makes worker progress observable,
and retains state and diagnostics for inspection and recovery.

## Install and upgrade

Download `promptgrinder_v1.0.0-rc.1_darwin_arm64.tar.gz` or
`promptgrinder_v1.0.0-rc.1_darwin_amd64.tar.gz` plus `checksums.txt` from the
GitHub release. Verify the exact archive checksum before extraction, then
follow the commands in `README.md`. The release is unsigned and not notarized;
it must not be described otherwise.

For an upgrade, preserve the installed binary as
`promptgrinder.previous`, replace only the executable, and run:

```sh
promptgrinder --version
promptgrinder doctor --terminal headless
```

PromptGrinder state under `${PROMPTGRINDER_HOME:-$HOME/.promptgrinder}` is not
an install target and must remain in place.

## Highlights

- Read-only readiness diagnostics through `promptgrinder doctor`, including
  deterministic JSON output.
- Explicit `promptgrinder setup` with dry-run support and narrowly scoped
  PromptGrinder-owned writes.
- Codex executable resolution before worker creation and reliable propagation
  into generated worker environments.
- Terminal.app, iTerm2, and headless execution adapters.
- Inspectable worker status, logs, events, cancellation, timeout,
  reconciliation, and retention behavior.
- Documented v1 compatibility expectations for commands, JSON, configuration,
  task formats, persisted state, and exit codes.

## Known limitations

- Only macOS and the Codex engine are supported.
- Release binaries are unsigned and not notarized.
- Homebrew distribution is deferred; verified direct download is the supported
  installation path.
- PromptGrinder does not install or authenticate Codex, edit shell profiles,
  grant Automation permissions, or manage macOS privacy settings.
- Exact supported application and macOS versions are pending qualification.

## Rollback

With no active workers, restore the preserved previous executable:

```sh
mv "$HOME/.local/bin/promptgrinder.previous" \
  "$HOME/.local/bin/promptgrinder"
promptgrinder --version
promptgrinder doctor --terminal headless
```

Rollback does not remove configuration, logs, events, summaries, or worker
state. Removing retained data is a separate explicit user action.
