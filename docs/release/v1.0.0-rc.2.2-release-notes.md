# PromptGrinder v1.0.0-rc.2.2 candidate notes

## Distribution change

`v1.0.0-rc.2.2` begins PromptGrinder's source-only GitHub release policy.
GitHub releases provide the automatic **Source code (zip)** and **Source code
(tar.gz)** links generated from the annotated tag. The PromptGrinder release
workflow does not build or attach compiled macOS, Linux, or Windows archives,
binary-only checksum files, or build metadata.

macOS installation will be supported through Homebrew using the tagged source.
The Homebrew formula is qualified and maintained separately; no compiled
Homebrew bottle or PromptGrinder binary archive is implied by this release
workflow.

Historical releases and their existing assets are unchanged.
