# PromptGrinder v1.0.0-rc.6.3 release notes

Status: release-prepared candidate; not tagged or published.

## Foreground by default

`promptgrinder run` already executes in the invoking terminal. RC.6.3 makes
`promptgrinder run-folder` consistent: ordered and parallel-worktree trains
now render live foreground progress unless the caller explicitly supplies
`--detach`.

- The generated default configuration now sets `run_folder.detach: false`.
- Command help, the slice-authoring skill templates, repository documentation,
  and the public guide use the shorter foreground-default command form.
- `--detach` remains supported as an explicit opt-in for a local background
  supervisor; its sequence inspection and cancellation behavior is unchanged.

Existing user or repository configuration can still set `run_folder.detach:
true` when detached execution is the local policy. Passing `--detach` or
`--detach=false` remains an invocation-level override.
