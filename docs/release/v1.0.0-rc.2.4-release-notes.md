# PromptGrinder v1.0.0-rc.2.4 candidate notes

Status: candidate source; not tagged or published.

RC.2.4 relaxes ordered slice discovery without changing execution ordering or
dependency safety.

## Highlights

- `run-folder` accepts an optional uppercase letter suffix after a two-digit
  ordering number. Both `08A-ranking-history.md` and
  `08A-implement-ranking-history.md` are recognized.
- Letter-suffixed generic names require the same explicit `id` and `type`
  frontmatter as other generic ordered names.
- Filename sorting remains deterministic, and `depends_on` entries must still
  resolve to an earlier slice in that order.
- The Slice DSL reference documents the filename grammar, frontmatter contract,
  path policy, and completion report.

## Distribution

GitHub releases remain source-only. Merging this candidate does not create a
tag or publish a release.
