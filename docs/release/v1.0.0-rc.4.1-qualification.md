## Compatibility review

- Token usage is additive persisted data; existing worker and sequence records
  without structured usage remain readable and report usage as unavailable.
- Only structured Codex terminal events provide usage. PromptGrinder does not
  estimate tokens or currency cost.
- `tokens_total` is input plus output; cached input and reasoning output are
  separately reported breakdowns and are not added a second time.
