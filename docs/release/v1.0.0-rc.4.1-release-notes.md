# PromptGrinder v1.0.0-rc.4.1 candidate notes

Status: candidate source; not tagged or published.

RC.4.1 makes run-folder resource use visible without inventing token or cost
figures.

## Highlights

- The Codex adapter records the structured `turn.completed` usage reported by
  the runtime: input, cached input, output, and reasoning-output tokens.
- Each run-folder sequence stores reported usage per slice and prints a
  per-slice breakdown plus aggregate total in its terminal and Markdown
  summaries, including any recorded recovery attempts.
- Missing runtime usage is shown as `unavailable`; PromptGrinder no longer
  searches free-form worker logs for token-looking text.
- Token counts are intentionally not converted into currency. Organizations may
  have different subscriptions, cached-input prices, and internal pricing
  policies, so cost estimation requires a separately declared policy.

## Distribution

GitHub releases remain source-only. Committing or merging this candidate does
not create a tag, publish a release, or update the Homebrew tap.
