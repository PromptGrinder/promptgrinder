# PromptGrinder v1.0.0-rc.2.3 candidate notes

Status: candidate branch; not tagged or published.

RC.2.3 is a stabilization release derived from real ordered-workflow testing.
It keeps the existing v1 command and persisted-state contracts while improving
the safety and observability of local engineering sequences.

## Highlights

- Run-folder output identifies the effective role, engine, and runtime-reported
  model in compact completed rows.
- Prompt, dependency, role, and Git preflight happens before a detached
  supervisor is announced.
- Dirty baselines list exact modified and untracked paths, while PromptGrinder
  sequence state remains outside the repository.
- `promptgrinder sequence cancel <id>` cancels active sequence work while
  preserving completed checkpoints for a later resume.
- Directory-shaped path patterns are rejected with an explicit `/**`
  correction, and optional `expected_paths` are checked before execution.
- `--commit-each` tells workers not to commit; unexpected worker commits retain
  the fail-closed ownership diagnostic.
- First-run setup and doctor output explain detected runtimes, terminals, shell,
  PATH, Git, storage, and headless capabilities.
- Conflicting discovery output names the existing target and confirms that no
  repository file was overwritten.

## Distribution

GitHub releases remain source-only. Publishing a release retains GitHub's
automatic source archives and triggers a review-only Homebrew formula update
pull request. Formula pull requests are never auto-merged.

Merging this candidate does not create a tag or publish a release.
