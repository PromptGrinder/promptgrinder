# v1.0.0-rc.2 final release gate

Decision: **NO-GO until every gate below has reviewed evidence.**

RC.2 is currently release-prepared but untagged, unqualified, and unpublished.
The source binary reports `v1.0.0-rc.2`.

## Required evidence

1. The candidate commit is reviewed and the worktree is clean.
2. Formatting, vet, module verification, shuffled tests, race tests, compiled
   acceptance tests, examples, and CI all pass.
3. Darwin arm64 and amd64 archives are built from the exact candidate with
   `CGO_ENABLED=0` and `-trimpath`, identified as Mach-O, checksummed, and the
   native artifact is executed for help/version/validation/dry-run smoke tests.
4. The [RC.2 qualification matrix](v1.0.0-rc.2-qualification.md) contains
   redacted clean-machine evidence for every claimed platform, adapter, and
   runtime.
5. Upgrade from RC.1, rollback to RC.1, state readability, prompt compatibility,
   and the intentional strict-frontmatter/completion changes are reviewed.
6. README, changelog, release notes, security/support guidance, and artifact
   names agree with the final version. No secrets, credentials, private prompts,
   generated state, binaries, or developer paths are tracked.

## Version and publication boundary

Only after the evidence is approved may a maintainer authorize changing version
metadata to `v1.0.0-rc.2`, creating the annotated tag, pushing it, and reviewing
the draft release produced by automation. Qualification does not itself grant
permission to tag, push, upload, or publish.

Never relabel pre-tag artifacts as RC.2. Rebuild from the exact annotated tag,
verify checksums and native smoke behavior again, then publish only with explicit
maintainer approval.

## Current blockers

- RC.2 version/tag authorization is pending.
- Tagged artifacts and checksums do not exist.
- Clean-machine matrix evidence is pending.
- Final human review and publication approval are pending.
