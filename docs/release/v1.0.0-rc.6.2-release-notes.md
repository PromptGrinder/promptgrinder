# PromptGrinder v1.0.0-rc.6.2 release notes

Status: release-prepared candidate; not tagged or published.

## Codex CLI compatibility without version churn

RC.6.2 changes Codex CLI compatibility from a hard exact-version allowlist to
a capability-based gate.

- Codex CLI `0.150.x` remains the known-qualified band.
- A CLI outside that band is no longer rejected merely for its version.
- PromptGrinder performs a read-only probe of `codex exec --help` and `codex
  exec resume --help` before worker creation.
- If all adapter-required flags are available, the CLI runs as **provisional**.
- If the probe fails, PromptGrinder blocks before creating a worker and names
  the unavailable capability.

This protects the command contract that PromptGrinder actually uses while
allowing compatible Codex patch and minor releases to work without a matching
PromptGrinder release. `promptgrinder doctor` presents the same qualified,
provisional, or failed-probe evidence without modifying a repository.

## Limits

The probe verifies the documented CLI surface used by PromptGrinder; it does
not prove model behaviour, account readiness, or every runtime path. The
`0.150.x` band remains the release-tested qualification baseline.
