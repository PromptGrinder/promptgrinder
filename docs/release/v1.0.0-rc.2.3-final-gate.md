# v1.0.0-rc.2.3 final release gate

The source reports `v1.0.0-rc.2.3`. Merging the candidate branch does not tag
or publish a release.

Before creating the annotated tag:

1. CI must pass on the merged `main` commit.
2. The qualification commands in
   [`v1.0.0-rc.2.3-qualification.md`](v1.0.0-rc.2.3-qualification.md)
   must pass from the exact merged commit.
3. `promptgrinder --version` must report `v1.0.0-rc.2.3`.
4. The source-only release and Homebrew-update workflows must validate without
   publishing or writing to the tap.
5. The worktree must be clean and contain no generated binary, local state,
   credential, private prompt, or developer-specific path.
6. A maintainer must explicitly authorize the annotated
   `v1.0.0-rc.2.3` tag and its push.

After the tag-triggered workflow creates the draft release, inspect it before
publication. Publishing the release may create a Homebrew formula update pull
request; tap CI must pass and a maintainer must merge that pull request
manually.
